Paso 1
HTML significa lenguaje de marcado de hipertexto. Es el código que define la estructura y el contenido de una página web. Este es tu editor de código, donde escribirás HTML.

Busca la línea 1 en el editor y escribe este texto:

Welcome to freeCodeCamp
Cuando termine, haga clic en el botón "verificar el código" para ver si es correcto.

------------------
Paso 2
HTML está compuesto por elementos. El primero que utilizarás es el elemento h1:

<h1>Welcome to freeCodeCamp</h1>
Comienza con una etiqueta de apertura ( <h1>), termina con una etiqueta de cierre ( </h1>) y tiene el texto que se mostrará entre las etiquetas.

Convierte tu texto Welcome to freeCodeCampen un elemento h1agregando una etiqueta de apertura antes de él y una etiqueta de cierre después.

Convierte el texto Full-Stack Curriculumen un elemento h2rodeándolo con etiquetas h2de apertura y cierre.
